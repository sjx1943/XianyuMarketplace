## 平台介绍

这是一个专为小区居民打造的**闲置物品展示交易小程序**。在这里，您可以：

- 把家中用不到的物品分享给有需要的邻居
- 找到邻居们分享的好物，省钱又环保
- 认识志趣相投的邻居，让小区更有人情味

---

## 核心功能

### 1. 发布闲置物品
轻松几步，将您的闲置物品发布到平台：
- 拍照上传，展示物品真实状态
- 填写简单描述，让邻居了解物品详情
- 设置合理价格或选择免费赠送

### 2. 浏览物品列表
- 按分类筛选，快速找到需要的物品
- 支持关键词搜索
- 查看物品详情和发布者信息

### 3. 即时沟通
- 在线私信，与发布者直接沟通
- 约定交付时间和地点
- 消息提醒，不错过任何回复

### 4. 交易记录
- 清晰的交易流程：发起 → 交付 → 完成
- 历史记录可查，交易有保障

## 常见问题

**Q：如何联系物品发布者？**
A：在物品详情页点击"我想要"或"联系对方"按钮，即可发起私信。

**Q：如何修改或删除已发布的物品？**
A：在"我的"页面找到"我发布的"，可以编辑或下架物品。

**Q：交易完成后如何确认？**
A：发布者确认交付后，接收方确认收到即可完成交易。
