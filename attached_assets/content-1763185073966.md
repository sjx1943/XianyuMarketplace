# 闲鱼二手交易平台

[Permalink: 闲鱼二手交易平台](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E9%97%B2%E9%B1%BC%E4%BA%8C%E6%89%8B%E4%BA%A4%E6%98%93%E5%B9%B3%E5%8F%B0)

一个基于Tornado框架开发的二手闲置物品交易平台，支持商品发布、实时聊天、订单管理、商品评价等功能。

## 功能特性

[Permalink: 功能特性](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E5%8A%9F%E8%83%BD%E7%89%B9%E6%80%A7)

- 商品发布和编辑
- 商品图片上传
- 商品分类和搜索
- 商品状态管理（在售、已售完等）
- 库存管理

### 💬 实时聊天

- WebSocket实时通信
- 好友系统
- 私人聊天室
- 消息历史记录
- 未读消息提醒
- 离线消息推送

### 📦 订单系统

- 订单创建和管理

### ⭐ 评价系统

## 技术栈

[Permalink: 技术栈](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E6%8A%80%E6%9C%AF%E6%A0%88)

- **后端**: Python 3.11 + Tornado
- **数据库**: MySQL (用户和商品数据) + MongoDB (聊天消息)
- **缓存**: Redis
- **前端**: HTML + CSS + JavaScript
- **部署**: Docker + Nginx + Supervisor

## 快速开始

[Permalink: 快速开始](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

### 方式一：Docker部署（推荐）

[Permalink: 方式一：Docker部署（推荐）](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E6%96%B9%E5%BC%8F%E4%B8%80docker%E9%83%A8%E7%BD%B2%E6%8E%A8%E8%8D%90)

1. **克隆项目**



```
git clone <repository-url>
cd MVC
```

2. **修改配置**

编辑 `docker-compose.yml` 文件，修改数据库密码等配置：



```
environment:
     MYSQL_ROOT_PASSWORD: your_secure_password
     MYSQL_PASSWORD: your_secure_password
```

3. **启动服务**



```
docker-compose up -d
```

4. **访问应用**

打开浏览器访问 `http://localhost`


### 方式二：手动部署

[Permalink: 方式二：手动部署](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E6%96%B9%E5%BC%8F%E4%BA%8C%E6%89%8B%E5%8A%A8%E9%83%A8%E7%BD%B2)

#### 环境要求

[Permalink: 环境要求](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E7%8E%AF%E5%A2%83%E8%A6%81%E6%B1%82)

- Python 3.11+
- MySQL 8.0+
- MongoDB 6.0+
- Redis 7.0+
- Nginx

#### 安装步骤

[Permalink: 安装步骤](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E5%AE%89%E8%A3%85%E6%AD%A5%E9%AA%A4)

1. **安装Python依赖**



```
pip install -r requirements.txt
```

2. **配置数据库**

修改 `config.ini` 文件中的数据库连接信息：



```
[mysql]
user = your_mysql_user
password = your_mysql_password
host = localhost
port = 3306
database = xianyu_db
charset = utf8mb4

[mongodb]
host = localhost
port = 27017
database = chat_db
```

3. **创建数据库**



```
CREATE DATABASE xianyu_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

4. **启动应用**



```
python app.py
```

5. **配置Nginx**

将 `nginx.conf` 复制到Nginx配置目录，并重启Nginx。

项目已支持转换为微信小程序版本，详细转换步骤：

### 1\. 准备工作

[Permalink: 1. 准备工作](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#1-%E5%87%86%E5%A4%87%E5%B7%A5%E4%BD%9C)

- 注册微信小程序账号
- 下载微信开发者工具
- 准备小程序AppID

### 2\. 创建小程序项目结构

[Permalink: 2. 创建小程序项目结构](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#2-%E5%88%9B%E5%BB%BA%E5%B0%8F%E7%A8%8B%E5%BA%8F%E9%A1%B9%E7%9B%AE%E7%BB%93%E6%9E%84)

```
miniprogram/
├── app.js
├── app.json
├── app.wxss
├── pages/
│   ├── index/          # 首页
│   ├── product/        # 商品页面
│   ├── chat/           # 聊天页面
│   ├── order/          # 订单页面
│   ├── profile/        # 个人中心
│   └── login/          # 登录页面
├── components/         # 组件
├── utils/             # 工具函数
└── images/            # 图片资源
```

### 3\. API适配

[Permalink: 3. API适配](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#3-api%E9%80%82%E9%85%8D)

小程序版本需要使用微信小程序的API：

- `wx.request()` 替代 `fetch()`
- `wx.connectSocket()` 实现WebSocket连接
- `wx.uploadFile()` 处理文件上传
- `wx.login()` 微信登录

### 4\. 页面转换

[Permalink: 4. 页面转换](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#4-%E9%A1%B5%E9%9D%A2%E8%BD%AC%E6%8D%A2)

将现有的HTML页面转换为小程序页面：

- `.html` → `.wxml`
- `.css` → `.wxss`
- `.js` → `.js` (适配小程序语法)

## API接口文档

[Permalink: API接口文档](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#api%E6%8E%A5%E5%8F%A3%E6%96%87%E6%A1%A3)

### 认证接口

[Permalink: 认证接口](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E8%AE%A4%E8%AF%81%E6%8E%A5%E5%8F%A3)

- `POST /login` \- 用户登录
- `POST /register` \- 用户注册
- `POST /forgot_password` \- 忘记密码
- `POST /reset_password` \- 重置密码

### 商品接口

[Permalink: 商品接口](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E5%95%86%E5%93%81%E6%8E%A5%E5%8F%A3)

- `GET /product_list` \- 获取商品列表
- `GET /product/detail/{id}` \- 获取商品详情
- `POST /product/upload` \- 发布商品

### 订单接口

[Permalink: 订单接口](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E8%AE%A2%E5%8D%95%E6%8E%A5%E5%8F%A3)

- `GET /orders` \- 获取订单列表
- `POST /orders` \- 创建订单
- `PUT /orders/{id}` \- 更新订单状态
- `DELETE /orders/{id}` \- 取消订单

### 评价接口

[Permalink: 评价接口](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E8%AF%84%E4%BB%B7%E6%8E%A5%E5%8F%A3)

- `GET /api/comments/{product_id}` \- 获取商品评价
- `POST /api/comments` \- 发布评价
- `GET /api/product/{id}/rating` \- 获取商品评分统计

### 聊天接口

[Permalink: 聊天接口](https://github.com/sjx1943/mytornado/tree/master/xianyu/agent_mvc#%E8%81%8A%E5%A4%A9%E6%8E%A5%E5%8F%A3)

- `GET /chat_room` \- 聊天室页面
- `WebSocket /ws/chat_room` \- WebSocket连接
- `POST /api/send_message` \- 发送消息
- `GET /api/messages` \- 获取消息历史
